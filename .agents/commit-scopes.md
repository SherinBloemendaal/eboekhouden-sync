# Commit scopes

Use one of these scopes in every Conventional Commit message.

| Scope | Area |
|-------|------|
| `worker` | The Cloudflare Worker API (auth, records, keys, members) |
| `rooms` | Durable Objects for Teamwerk presence |
| `dashboard` | The web dashboard |
| `db` | D1 schema and migrations |
| `spec` | The protocol specification |
| `repo` | Repository setup, CI, docs that are not the spec |
